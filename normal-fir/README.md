# Normal FIR Filter

A VHDL implementation of a normal FIR (Finite Impulse Response) filter using component instantiation.

## Components
- `FIR_Filter.vhd` — Top-level FIR design
- `Four_bit_multiplier.vhd` — Multiplier component
- `RCA_8bit.vhd` — 8-bit ripple-carry adder
- `DFF.vhd` — D flip-flop
- `Full_Adder.vhd` and `half_adder.vhd` — Arithmetic building blocks
- `FIR_TBW.vhd` — Simulation testbench

## Tools
- VHDL
- Xilinx ISE
- ISim (if used)
