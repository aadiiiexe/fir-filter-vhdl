# Parallel-Processed FIR Filter

A parallel-processed FIR filter implemented in VHDL using component instantiation.

## Source Files
- `FIR_Parallel_Processing.vhd` — Top-level parallel FIR design.
- `Four_bit_multiplier.vhd` — Multiplier component.
- `MULTIPLIER_4_BIT.vhd` — Additional multiplier module.
- `RCA_8bit.vhd` — 8-bit ripple-carry adder.
- `DFF.vhd` — D flip-flop.
- `Full_Adder.vhd` — Full-adder component.

## Tools
- VHDL
- Xilinx ISE

Simulation and verification details will be added as the project is documented.
